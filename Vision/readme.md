# Vision Experiments

`vision_2_cico.magma`–`vision_5_cico` implement the CICO-1 resultant experiments for 2–5 rounds of Vision, reporting the intermediate polynomial degrees, resultant costs/runtimes, and recovered solutions. The 2-round case uses direct successive resultants, while the higher-round scripts apply the degree-reduction strategy used in the paper and verify the final candidates by evaluating the original permutation.
